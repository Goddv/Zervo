# Icon

The icon is authored in **Apple's Icon Composer** — `Zervo.icon` is the source
of truth. It layers three SVGs (background, orbit ring, Z glyph) with
translucency and a neutral shadow.

| File | Role |
|------|------|
| `Zervo.icon/` | Icon Composer document — edit this |
| `zervo-1-background.svg`, `zervo-2-ring.svg`, `zervo-3-glyph.svg` | the layers it references |
| `zervo-icon-default.svg` | layers composed flat, opaque backdrop — shipped in the app |
| `zervo-icon-transparent.svg` | same, with the translucent backdrop — the in-app "Transparent" option |
| `zervo-1024.png` | `zervo-icon-default.svg` rendered at 1024², committed so releases build without Xcode |
| `Zervo.icns` | generated by `scripts/make-icns.sh`, not committed |

## After editing the artwork

1. Edit `Zervo.icon` in Icon Composer (or the layer SVGs directly).
2. Mirror the change into `zervo-icon-default.svg` / `zervo-icon-transparent.svg`
   — these are what the app embeds for its Dock icon.
3. Re-render the PNG and the icns:

   ```bash
   ./scripts/make-icns.sh
   ```

`actool` could compile `Zervo.icon` directly, but that requires a full Xcode
install; composing from the layers keeps the build working with only the
Command Line Tools.
